# 로그라이트 퍼즐 게임 기획 문서 v0.1

## 1. 게임 핵심 컨셉

하나의 Spark(점화)에서 시작해 제한된 슬롯에 반응 오브젝트를 배치하고, 연쇄 반응을 설계하여 여러 Explosion(Bomb)의 총 반응량(데미지)을 목표 이상으로 만드는 로그라이트 퍼즐 게임.

핵심 재미:

- 많은 콘텐츠를 추가하는 것이 아니라 적은 규칙이 서로 상호작용하도록 설계
- 플레이어는 "오브젝트를 사용하는 것"이 아니라 "반응 회로를 설계하는 것"

---

# 2. 기본 게임 루프

## 스테이지 시작

각 스테이지에는:

- 클리어 목표 반응량(데미지)
- 플레이어가 보유한 오브젝트
- 사용할 수 있는 슬롯 수

가 존재한다.

---

## 회로 설계

기본 구조:

Spark
↓
[슬롯]
↓
[슬롯]
↓
[슬롯]
↓
Bomb

플레이어는 보유한 오브젝트를 슬롯에 배치한다.

목표:

- Spark에서 시작
- 중간 과정에서 반응량을 최대한 증가/변형
- 마지막에는 Explode 속성을 가진 Bomb로 종료

---

## 실행

플레이어가 Ignite를 실행하면 자동으로 연쇄 반응 진행.

결과:

Bomb 1 데미지

- Bomb 2 데미지
- Bomb 3 데미지

=
총 반응량

목표치를 넘으면 스테이지 클리어.

---

# 3. 로그라이트 성장

스테이지 클리어 후 보상 선택.

예:

- 슬롯 증가
- 새로운 오브젝트 획득
- 기존 오브젝트 강화
- 새로운 조합 해금

초기에는 짧은 회로만 가능하지만,
성장할수록 긴 회로와 분기 구조를 만들 수 있음.

---

# 4. 핵심 물리량: Reaction Value (RV)

모든 반응은 반응량(RV)을 가진다.

Spark가 생성하는 초기 RV:

RV = 1

모든 속성은 RV를 조작한다.

---

# 5. 속성 시스템 (현재 확정)

## Ignite

역할:
반응 시작

예:
Spark → RV 1 생성

---

## Explode

역할:
반응량을 데미지로 변환

예:
RV 50 → Explosion Damage 50

폭발 시 해당 RV는 소비됨.

---

## Amplify

역할:
반응량 증가

예:
RV 10 → RV 20

---

## Store

역할:
반응량 축적

예:

RV 10 저장

- RV 20 저장

=
Stored RV 30

이후 Explode 등에 사용.

---

## Split

역할:
반응 분기

예:

RV 10

↓

RV 5
RV 5

기본적으로 복제가 아니라 분배.

---

## Convert

역할:
반응 성질 변경

RV 자체는 유지.

예:
Fire → Ice

---

## Echo

역할:
동일 반응 반복

예:

Explosion 1회

↓

Explosion 추가 발생

---

# 6. 기본 오브젝트

| 오브젝트 | 속성    |
| -------- | ------- |
| Spark    | Ignite  |
| Bomb     | Explode |
| Fuel     | Amplify |
| Crystal  | Store   |
| Prism    | Split   |
| Catalyst | Convert |
| Mirror   | Echo    |

---

# 7. 설계 방향

7개의 속성으로 먼저 프로토타입 제작.

2속성 조합 오브젝트와 업그레이드는 이후 확장.

중요한 것은 콘텐츠 양이 아니라:

- Ignite → 가공 → Explode
- RV 증가/저장/분배/반복
- 슬롯 제한

이라는 핵심 시스템이 재미있는지 검증하는 것.

---

# 8. 개발 우선순위

1. 슬롯 시스템 구현
2. 오브젝트 배치 시스템 구현
3. Spark → Bomb까지 반응 흐름 구현
4. RV 계산 시스템 구현
5. 기본 7개 속성 구현
6. 스테이지 목표/클리어 조건 구현
7. 로그라이트 보상 시스템 추가

목표:
작은 프로토타입으로 "반응 회로를 설계하는 재미" 검증.
